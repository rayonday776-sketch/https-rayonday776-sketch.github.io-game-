# Chroniques des Âges

Grand strategy dans le navigateur : un continent procédural qui grandit de l'Antiquité à l'ère moderne.

- Relief, fleuves, lacs, climats et biomes générés ; carte façon atlas ancien.
- Villes qui s'étendent anneau par anneau, quartiers et bâtiments visibles au zoom, murailles, faubourgs, chemins de fer.
- Économie de marché par ville et partis politiques (repris du mod EcoPol).
- Dirigeants aux portraits procéduraux animés, gazette annuelle dont le style suit l'époque.

**Jouer** : ouvrir `index.html` via un serveur local (`python3 -m http.server`) puis http://localhost:8000. Ajouter `?seed=1234` pour rejouer un monde.

Le design complet est dans [DESIGN.md](DESIGN.md).
